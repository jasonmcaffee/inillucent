# The compatibility harness's data

This directory is the parity contract. Nothing in it is generated by hand, and
nothing in it is read by a production crate.

| path | what it is |
|---|---|
| `sqlite-3.53.4.toml` | the parity manifest: one row per capability inillucent owes, including the ones nothing is written for yet |
| `sources.toml` | every documentation page a capability row may cite; a source that is not here is a dead link |
| `syntax.toml` | the syntax obligation register: one row per published syntax diagram, with the statements that must parse and the ones that must not |
| `syntax-report.md` | the register rendered, so the parser's coverage is readable rather than inferred |
| `corpus/select/` | the foundational SELECT corpus: a schema the pinned binary builds and one query per line |
| `errors.toml` | the stable error table, from which `inillucent-base`'s Rust table is generated at build time |
| `limits.toml` | the run-time limits, generated the same way |
| `reference/sqlite-3.53.4.toml` | the pinned oracle build: version, compile options, run-time settings, and a published SHA3-256 for every artifact |
| `oracle/sqlite_driver.c` | the oracle, compiled from the pinned amalgamation and run as a child process |
| `results/*.jsonl` | recorded test outcomes, one file per platform; the only thing that can move a capability to `pass` |
| `baseline/` | the untouched retrieval engine, captured so a later story can prove it did not disturb it |
| `compat-report.json` | the machine-readable release gate, generated from the manifest and the results |
| `compat-report.md` | the same, as a scorecard |
| `fixtures/` | licensed upstream fixtures and inillucent-authored ones, kept apart so their licences do not mix |
| `api/` | C symbol and profile manifests, and the ABI probes that check them; phase 12 |

Regenerate the report with:

```bash
cargo run -p inillucent-compat --bin inillucent-evidence            # run the suites, record results
cargo run -p inillucent-compat --bin inillucent-manifest -- report  # generate the report from them
```
