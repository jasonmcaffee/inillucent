# Fixtures

Two kinds, deliberately kept apart.

- `upstream/` holds files taken from a project with its own licence. Each
  subdirectory carries that project's licence text and a note saying which
  release it came from. Nothing here is modified; a fixture that needed editing
  is a inillucent fixture instead.
- `inillucent/` holds fixtures this repository wrote. These are the ones a test may
  regenerate.

A fixture with no provenance is not a fixture. Add the note first.
